# 마이 북 (my_toon) 생성 — toon_create.py

현재 PC 에 보관 중인 웹툰 폴더/이미지를 분석해서 `my_toon_*` 테이블로 DB 화하고,
이미지를 기존 웹툰 서비스와 같은 형태(`D:\booktoon\{아이디}\{회차번호}\001.jpg ...`)로 복사합니다.

## 실행

```powershell
# 1) 폴더 구조 분석만 (복사/DB 없음) — 작업 전에 먼저 확인
python toon_create.py --TYPE 1 --name "도시정벌 1부" --path "D:\mynas\도시정벌 1부(01~12)" --dry-run

# 2) 신규 등록 (--bookid 없음 → 아이디 = 현재 일시 YYYYMMDDHHMMSS)
python toon_create.py --TYPE 1 --bookid "" --name "도시정벌 1부" --path "D:\mynas\도시정벌 1부(01~12)"

# 3) 이어하기 / 다시 반영 (같은 아이디로)
python toon_create.py --TYPE 1 --bookid 20261016093015 --name "도시정벌 1부" --path "D:\mynas\도시정벌 1부(01~12)"
```

| 옵션 | 설명 |
|---|---|
| `--TYPE` | 원본 폴더 구조 TYPE (아래 표). 기본 1 |
| `--bookid` | 비우면 신규 생성. 숫자 아이디를 주면 그 아이디로 등록/갱신 |
| `--name` | 제목 (`my_toon_info.title`) |
| `--path` | 원본 폴더 |
| `-o, --output` | 복사 루트 (기본 `D:/booktoon`) |
| `--dry-run` | 분석 결과만 출력 |

- 같은 크기의 파일이 이미 복사돼 있으면 건너뜁니다 → 중단돼도 같은 `--bookid` 로 다시 실행하면 이어서 진행.
- 회차 단위로 커밋합니다. 해당 회차의 이미지 행은 매번 새로 교체합니다.
- 실행이 끝나면 정보 파일 `D:\booktoon\{아이디}\{아이디}_{제목}.txt` 를 다시 씁니다
  (크롤러의 `279_나 혼자만 레벨업.txt` 와 같은 형식, 회차 목록은 `회차 | 장수 | 제목 | 원본 폴더`).
- PowerShell 5.1 은 `--bookid ""` 의 빈 문자열을 빼고 넘기므로, 값 없는 `--bookid` 도 신규 생성으로 처리합니다.

## 압축 파일 (zip)

분석 전에 원본 폴더 바로 아래의 `*.zip` 을 확인합니다 (`--dry-run` 이면 해제 예정만 출력).

- 같은 이름의 폴더가 **있으면** zip 은 무시 (`도시정벌 3부 01.zip` ↔ `도시정벌 3부 01\`).
- 폴더가 **없으면** zip 을 풀어서 폴더를 만든 뒤 진행.
  - 이미지 파일만, zip 안의 폴더 경로는 버리고 회차 폴더 바로 아래에 풉니다.
  - UTF-8 플래그 없는 zip(한글 Windows 압축)은 파일명을 cp949 로 해석합니다.
  - `{폴더}.unzip_tmp` 에 다 푼 뒤 이름을 바꾸므로, 중간에 끊겨도 반쯤 풀린 폴더가 남지 않습니다.

## 아이디 (bookid) 자료형

- 신규 아이디 = `YYYYMMDDHHMMSS` 14자리 숫자 (예: `20261016093015`).
- `BIGINT` 최대값 9,223,372,036,854,775,807(19자리) 안이라 문제 없음. `INT`(최대 21억, 10자리)였다면 넘침.
- 같은 초에 이미 있는 아이디면 1초 기다렸다가 다시 만듭니다.
- 사이트 웹툰 아이디(`toon_info.toon_id`, 5~6자리)와 자릿수가 달라 `D:\booktoon\{아이디}` 폴더가 겹치지 않습니다.

## 테이블 (book_sql/30_my_toon_테이블생성.sql)

실행 시 `CREATE TABLE IF NOT EXISTS` 로 자동 생성됩니다.

| 기존 | 신규 | 비고 |
|---|---|---|
| toon_info | my_toon_info | PK `my_toon_id`. 사이트 수집용 컬럼(source_url, rating 등) 제외, `src_type` / `src_path` / `image_root` / `total_image_cnt` 추가 |
| toon_episode | my_toon_episode | `episode_code` = `my-{my_toon_id}-{episode_no}`. `episode_title` = 원본 폴더명, `src_dir` 추가. `(my_toon_id, episode_no)` 유니크 |
| toon_episode_image | my_toon_episode_image | `org_url` 대신 `src_file` (원본 파일 경로) |

이미지 `page_no` 는 원본 파일명 숫자 순서대로 **1부터 다시 매깁니다**. 복사 파일명도 `001.jpg, 002.jpg ...` (확장자는 소문자).
원본 번호가 000 부터 시작하거나 중간에 빠져 있어도 뷰어에서는 연속된 순번이 됩니다. 원본 이름은 `src_file` 에 남습니다.

## 폴더 구조 TYPE

새 형태의 폴더가 나오면 TYPE 을 추가하고 여기에 기록합니다. (`toon_create.py` 의 `ANALYZERS` 에 함수 추가)

### TYPE 1 — 루트 / 회차폴더 / 이미지

```
D:\mynas\도시정벌 1부(01~12)\
  도시정벌 01\001.jpg, 002.jpg ...
  도시정벌 02\001.jpg, 002.jpg ...
  ...
```

- 루트 바로 아래 폴더 하나 = 회차 1개.
- 회차 번호 = 폴더명의 **마지막 숫자** (`도시정벌 01` → 1, `도시정벌 2부 01` → 1).
- 회차 폴더 바로 아래의 이미지(`jpg jpeg png gif webp bmp`)만 사용. `Thumbs.db` 등 다른 파일은 무시.
- 이미지 순서 = 파일명 숫자 순 정렬 (`2.jpg` < `10.jpg`).
- 분석 실패(중단): 폴더명에 숫자 없음 / 회차 번호 중복 / 회차 폴더 안에 하위 폴더 있음 → 새 TYPE 필요.
- 경고만(계속 진행): 이미지 없는 회차 폴더(건너뜀), 원본 파일 번호 빠짐, 빠진 회차 번호, 루트에 흩어진 이미지(무시).

### TYPE 2 — TYPE 1 구조 + 펼침면(한 장에 2페이지) 분리

```
D:\mynas\도시정벌 5부\
  도시정벌 5부 01권\0001.jpg (1650x1275, 왼쪽 6쪽 | 오른쪽 7쪽) ...
```

- 폴더 분석은 TYPE 1 과 같습니다 (회차폴더 끝 숫자 = 회차 번호).
- **가로 > 세로인 이미지(JPEG/GIF/PNG/BMP) = 펼침면** → 가운데에서 잘라 **왼쪽 → 오른쪽** 순서로 2페이지, `.jpg` 로 저장 (한국 만화책 읽는 순서).
- 세로 이미지(표지·뒷표지 등 단면)는 자르지 않고 1페이지 그대로. 한 권 전체가 단면이어도 됩니다 (권/이미지마다 판단).
- 형식은 확장자가 아니라 파일 앞부분(JPEG/PNG/GIF/BMP 서명)으로 판단하고, 자르지 않은 페이지는 실제 형식 확장자로 저장합니다.
- 분리는 Windows 기본 `System.Drawing`(PowerShell)로 합니다. 이 서버는 PyPI 접속이 막혀 Pillow 를 설치할 수 없어서입니다.
  JPEG 품질 92 로 다시 저장 → 용량이 원본보다 커집니다 (5부: 원본 1.2GB → 1.8GB).
- 스캔이 한쪽으로 치우친 펼침면은 가운데 자르기라 옆 페이지가 조금 보이거나 가장자리가 잘릴 수 있습니다 (예: 6부 049권 GIF).
- `my_toon_episode_image.src_file` 끝에 `#L` / `#R` 로 원본의 어느 쪽인지 남깁니다 (예: `.../0001.jpg#L`).
- `image_cnt` / 정보 파일 `장수` 는 분리 후 페이지 수입니다.
- 같은 아이디를 다른 TYPE 으로 다시 등록하면 (예: 5부 TYPE 1 → 2) 이전에 만든 회차 폴더(`D:\booktoon\{아이디}\{숫자}`)를 지우고 새로 만듭니다.

### TYPE 3 — 분할본(권) 3개 = 회차 1개 + 단행본 통째 폴더 (펼침면 분리 포함)

폴더의 '권' 번호와 실제 회차(단행본 `도시정벌IX · NN`)가 다릅니다. 이미지를 보고 확인한 규칙은 다음과 같습니다.

- 분할본마다 첫 장이 **표지(분할본 번호) | 제목 페이지**입니다. 표지 번호는 1~232 모두 폴더명과 같습니다.
  제목 페이지 번호는 **⌈N/3⌉** 입니다. 예: 1·2·3권 → `IX · 01`, 193~195 → `IX · 65`, 231 → `IX · 77`, 232 → `IX · 78`.
  (분할본 4~45, 47~95권은 제목 페이지에 번호가 없는 공통 그림이지만, 표지 번호와 앞뒤 순서로 규칙이 이어짐을 확인)
- 그래서 **루트 바로 아래 분할본 N → 회차 ⌈N/3⌉**. 분할본 1~231 → 회차 1~77 (회차당 3개, 이미지 약 88장 → 약 176페이지).
- **하위 폴더가 있는 폴더**(`도시정벌9 78권-98권 ...`) 아래의 이미지 폴더 = 단행본 통째 → **폴더명 끝 숫자 = 회차** (78~98).
- 같은 회차가 양쪽에 있으면 단행본 통째를 씁니다. **분할본 232 = 단행본 78 의 앞 29장과 같은 내용**(이미지 대조)이라 제외합니다.
- 분할본 2·3번째의 첫 장(표지 | 제목 페이지)은 원본 그대로 회차 중간에 남겨 둡니다 (분할본 경계 표시).
- 펼침면 분리는 TYPE 2 와 같습니다. 단행본 통째 폴더는 화면 캡처라 위아래·좌우에 흰 여백과 마우스 커서가 있어서,
  **흰 여백 바깥 상자를 구한 뒤 가운데 기준 대칭으로 잘라** 좌/우 페이지를 만듭니다 (여백 제거).
- 회차 제목(`episode_title`) = `1회 ← 도시정벌 9부 1권 ~ 도시정벌 9부 3권`, `78회 ← 도시정벌9 78`. `src_dir` = 첫 분할본 폴더.
- BMP 도 펼침면으로 판단합니다 (95권이 BMP).

### TYPE 4 — 한 폴더에 전체 페이지 + 회차 나눔 파일 (펼침면 분리 포함)

```
D:\mynas\도시정벌 디퍼런스 1부완\
  00001.jpg ... 01470.jpg   ← 단행본 여러 권이 권 구분 없이 이어진 페이지
```

- 회차 폴더가 없으므로 **챕터 표제 페이지(`Chapter N 제목`)를 이미지로 찾아** 회차 나눔 파일에 시작 파일을 적습니다.
- 회차 나눔 파일 기본 위치: `01_Claude_job/mybook_chapters/{원본 폴더명}.txt` (`--chapters` 로 바꿀 수 있음).
  한 줄 = `회차번호<TAB>시작 파일<TAB>제목`, `#` 은 주석. 회차 = 시작 파일 ~ 다음 회차 시작 바로 앞.
- 회차 제목(`episode_title`)은 파일의 제목, `src_dir` = 루트.
- 펼침면 분리는 TYPE 2 와 같습니다.
